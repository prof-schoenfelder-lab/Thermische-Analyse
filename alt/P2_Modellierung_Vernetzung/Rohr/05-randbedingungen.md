# 5 · Randbedingungen <small>(Mechanical)</small>

<div class="task-banner" data-tabs="Aufgabe=../|a) Vollmodell=../01-material/|b) Viertelmodell=../b-viertelmodell/|c) Rotationssym.=../c-rotationssymmetrie/|Vergleich=../vergleich/" markdown>
🎯 **Jetzt:** Temperaturen anbringen — **innen 100 °C, außen 20 °C**
</div>

??? tip "Kurzanleitung: Temperatur auf Fläche(n) anbringen"
    1. Mit dem **Flächenauswahltool** die **Fläche(n) auswählen**
        ![Flächenauswahltool](../images/rohr_Untitled_1.png)
        - Mehrfachauswahl: **STRG gedrückt halten**
        - Drehen: **mittlere Maustaste** · Verschieben: **mittlere Maustaste + STRG**
    2. **Steady-State Thermal** im **Strukturbaum** auswählen
    3. `Reiter Environment → Temperature` anklicken
        ![Environment → Temperature](../images/rohr_Untitled_2.png)
    4. Im Detailfenster den Temperaturwert bei **Magnitude** eintragen
        ![Detailfenster](../images/rohr_Untitled_3.png)
    5. Randbedingung sinnvoll umbenennen — `Rechtsklick → Rename` (oder F2),
       z.B. „Innenseite (100 °C)"
