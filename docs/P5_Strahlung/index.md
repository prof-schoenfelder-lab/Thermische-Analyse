# Praktikum 5: Strahlung

## Lernziele

!!! abstract "Lernziele"
    - **Wärmestrahlung** als Randbedingung verstehen: Emissionsgrad,
      Stefan-Boltzmann-Gesetz, Nichtlinearität
    - Unterschied **Strahlung zur Umgebung** (To Ambient) und **Strahlung
      von Körper zu Körper** (Surface to Surface, Enclosure)
    - **Anisotrope Wärmeleitung** kennenlernen (richtungsabhängige
      Wärmeleitfähigkeit)

## Inhalte

- Grundlagen der Wärmestrahlung (Wiederholung aus der
  [Übersicht Randbedingungen](../P3_Randbedingungen_Postprocessing/Randbedingungen.md#warmestrahlung-radiation))
- Surface-to-Surface-Strahlung in ANSYS: Enclosure, Enclosure Type
  (Open/Perfect), View-Faktoren
- [Beispiel: Cerankochfeld](Cerankochfeld.md) — Strahlung vom Heizelement
  auf die Kochfläche mit anisotroper Wärmeleitung der Glaskeramik
