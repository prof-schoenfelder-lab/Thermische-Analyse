# :material-information-variant-box: Einleitung

Nach dem [Vorzeigebeispiel](../02_Vorzeigebeispiel/Aussenwand/index.md) wird der
Ablauf nun eigenständig wiederholt. Die drei Übungen bauen aufeinander auf:
von der besser gedämmten Wand über den ungedämmten Altbau bis zur Sanierung
nach Gebäudeenergiegesetz. Alles bereits Behandelte lässt sich im
Vorzeigebeispiel nachschlagen.

Jede Frage darf bis zu fünfmal beantwortet werden. Danach wird die Lösung
angezeigt. Richtige Antworten werden sofort bestätigt.

!!! tip "Gegenrechnen lohnt sich"
    Zu jeder Übung lässt sich das Ergebnis mit der
    [analytischen Lösung](../02_Vorzeigebeispiel/Aussenwand/analytische-loesung.md)
    von Hand prüfen. Stimmen FEM und Handrechnung nicht überein, steckt ein
    Fehler im Modell.

Viel Erfolg!
