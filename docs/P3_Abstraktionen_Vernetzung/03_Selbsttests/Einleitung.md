oft. Danach wird die Lösung angezeigt.

!!! tip "Plausibel prüfen mit der Energiebilanz"
    - Alle Temperaturen und Konvektionen auf **Solution** ziehen (Reaction Probe)
    - Im stationären Zustand ist die Summe null
    - Passt sie nicht, sitzt eine Randbedingung auf der falschen Kante
