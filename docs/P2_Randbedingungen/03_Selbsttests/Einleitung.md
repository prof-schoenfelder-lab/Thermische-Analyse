# :material-information-variant-box: Einleitung

Nach dem [Vorzeigebeispiel](../02_Vorzeigebeispiel/Vakuumroehre/index.md)
wenden Sie die Randbedingungen nun selbst an. Die Übungen werden von Mal zu Mal
umfangreicher:

| Übung | Neu in dieser Übung |
|---|---|
| 1 · Heizungsrohr | Konvektion und Strahlung auf derselben Fläche |
| 2 · Kühlkörper | Wärmestrom (W) auf einem Teil einer Fläche |
| 3 · Erdkabel | Wärmeerzeugung im Körper, feste Temperatur, drei Körper |

Zahlenfragen dürfen bis zu fünfmal beantwortet werden, Auswahlfragen weniger
oft. Danach wird die Lösung angezeigt.

!!! tip "Plausibel prüfen mit der Energiebilanz"
    - Temperatur, Konvektion und Strahlung auf **Solution** ziehen (Reaction Probe)
    - Die vorgegebenen Wärmeströme dazuzählen
    - Im stationären Zustand ist die Summe null
    - Passt sie nicht, sitzt eine Randbedingung auf der falschen Fläche

Viel Erfolg!
