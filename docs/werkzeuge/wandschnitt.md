# Wandschnitt 2D

Stationäre Wärmeleitung in 2D, live im Browser gerechnet:

- Wandprofil aus Rechtecken zusammenstellen oder eine Vorlage wählen
- Kanten im Bild ziehen, das Temperaturfeld rechnet sofort neu
- Ergebnisse mit Ihrer ANSYS-Rechnung vergleichen: Oberflächentemperaturen, Wärmeströme, f_Rsi und ψ
